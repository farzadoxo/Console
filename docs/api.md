# API Documentation
This file will help you to undrestand how "CONSOLE" work!

## Authentication
### Register
```json
"URL":"/api/auth/register/",
"REQUEST":[username,email,password],
"METHOD":["POST"],
"RESPONSE":"201-CREATED"
```

### Login 
```json
"URL":"/api/auth/login/",
"REQUEST":[username,password],
"METHOD":["POST"],
"RESPONSE":"200-OK"
```

### Logout
```json
"URL":"/api/logout/",
"REQUEST":[username],
"METHOD":["GET"],
"RESPONSE":"200-OK"
```
